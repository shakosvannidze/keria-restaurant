# რესტორანი „კერია“

რესტორან „კერიას“ თანამედროვე და სრულად რესპონსიული ვებსაიტი. მომხმარებელს შეუძლია გაეცნოს რესტორანს, დაათვალიეროს ფოტოგალერეა და 16-გვერდიანი მენიუ, მიიღოს საკონტაქტო ინფორმაცია და გახსნას რესტორნის მდებარეობა რუკაზე.

## ცოცხალი ვერსია

[keriagori.ge](https://keriagori.ge/)

## ძირითადი შესაძლებლობები

* სრულად რესპონსიული დიზაინი
* ქართული, ინგლისური და რუსული ინტერფეისი
* ინტერაქტიული 16-გვერდიანი მენიუ
* მენიუს კლავიატურით მართვა
* JavaScript-ის გარეშე ხელმისაწვდომი მენიუს გვერდი
* მობილური ნავიგაცია
* ფოტოგალერეა
* საკონტაქტო და მდებარეობის ინფორმაცია
* Google Maps-ის მარშრუტი
* Open Graph და სოციალური ქსელების მეტამონაცემები
* Schema.org `Restaurant` სტრუქტურირებული მონაცემები
* კლავიატურასა და ეკრანის წამკითხველზე მორგებული ინტერფეისი
* შემცირებული ანიმაციის რეჟიმის მხარდაჭერა

## ლოკალურად გაშვება

ჩამოტვირთეთ ან დააკლონირეთ რეპოზიტორია:

```bash
git clone YOUR-REPOSITORY-URL
```

გახსენით პროექტის საქაღალდე და გაუშვით Live Server-ის გამოყენებით.

პროექტი ასევე შეგიძლიათ გაუშვათ შემდეგი ბრძანებით:

```bash
npx serve .
```

## მენიუ

რესტორნის მენიუ წარმოდგენილია 16 სრული გვერდის სახით. ინტერაქტიული მენიუ მხარს უჭერს:

* წინა და შემდეგ გვერდზე გადასვლას
* გვერდის ნომრით არჩევას
* კლავიატურის ისრებით მართვას
* `Escape` ღილაკით დახურვას
* მენიუს ორიგინალი სურათის გახსნას

JavaScript-ის გამორთვის შემთხვევაში მენიუ ხელმისაწვდომია `menu.html` გვერდზე.

## რესპონსიულობა და ხელმისაწვდომობა

ვებსაიტი მორგებულია მობილურ, პლანშეტურ და დესკტოპ მოწყობილობებზე. ინტერაქტიული ელემენტების გამოყენება შესაძლებელია როგორც მაუსითა და სენსორული ეკრანით, ასევე კლავიატურით.
